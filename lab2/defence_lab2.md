#### **1. Общая характеристика цепочечных команд**

**Определение цепочек:**

- Цепочки — последовательности элементов (символы, числа и т.д.), хранящиеся в соседних ячейках памяти в виде двоичных кодов.
- **Ограничение:** размер элементов фиксирован — байт, слово (2 байта) или двойное слово (4 байта).

**Особенности обработки:**

- Каждая цепочечная команда обрабатывает **только текущий элемент** цепочки и автоматически переходит к следующему.
- **Регистры-указатели:**
  - `ESI` — адрес текущего элемента **источника**.
  - `EDI` — адрес текущего элемента **приёмника**.
- **Направление обработки** определяется флагом `DF` (регистр `EFLAGS`):
  - `DF = 0` (команда `CLD`) → обработка в направлении **возрастания адресов** (регистры `ESI`/`EDI` **инкрементируются**).
  - `DF = 1` (команда `STD`) → обработка в направлении **убывания адресов** (регистры `ESI`/`EDI` **декрементируются**).
- **Шаг изменения адресов:**
  - Байт: ±1,
  - Слово: ±2,
  - Двойное слово: ±4.

**Подготовка к выполнению:**

- Перед вызовом команды необходимо загрузить в `ESI` и `EDI` начальные адреса обрабатываемых элементов.
- Для загрузки адресов используются:
  - `LEA` (Load Effective Address): `LEA регистр, метка_памяти`,
  - `OFFSET`: `MOV ESI, OFFSET метка_памяти`.

---

#### **2. Префиксы повторения**

Префиксы указываются **перед** цепочечной командой и управляют количеством её повторений.

- **Регистр-счётчик:** `ECX` (указывает количество итераций).
- **Основные префиксы:**

| Префикс      | Условие продолжения цикла                        | Применение                                          |
| ------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------- |
| `REP`             | `ECX ≠ 0`                                                            | Пересылка данных (например,`MOVSB`). |
| `REPE`/`REPZ`   | `ECX ≠ 0` **и** `ZF = 1` (элементы равны)      | Поиск совпадающих элементов.         |
| `REPNE`/`REPNZ` | `ECX ≠ 0` **и** `ZF = 0` (элементы не равны) | Поиск несовпадающих элементов.     |

**Важно:**

- После каждой итерации значение `ECX` уменьшается на 1.
- Цикл прерывается при нарушении условий префикса.

#### **3. Пересылка цепочек (команды `MOVSB/W/D`)**

**Синтаксис:**

```asm
MOVS адрес_приёмника, адрес_источника  ; Ассемблер автоматически преобразует в MOVSB/W/D
```

**Алгоритм работы:**

1. Копирует элемент из ячейки `[ESI]` в `[EDI]`.
2. Автоматически корректирует `ESI` и `EDI` в зависимости от `DF` и размера элемента.

**Последовательность действий для копирования цепочки:**

1. Установить направление обработки (`CLD` или `STD`).
2. Загрузить начальные адреса:
   ```asm
   LEA ESI, источник  ; или MOV ESI, OFFSET источник
   LEA EDI, приёмник  ; или MOV EDI, OFFSET приёмник
   ```
3. Загрузить количество элементов в `ECX`:
   ```asm
   MOV ECX, количество_элементов
   ```
4. Выполнить команду с префиксом `REP`:
   ```asm
   REP MOVSB  ; для байтов
   ```

**Пример (копирование 100 байт):**

```asm
CLD           ; обработка в сторону увеличения адресов
LEA ESI, SOURCE
LEA EDI, DEST
MOV ECX, 100
REP MOVSB     ; копирование 100 байт из SOURCE в DEST
```

#### **4. Сравнение цепочек (команды `CMPSB/W/D`)**

**Синтаксис:**

```asm
CMPS адрес_приёмника, адрес_источника  ; Преобразуется в CMPSB/W/D
```

**Алгоритм:**

- Вычитает элемент из `[EDI]` из элемента в `[ESI]` (результат не сохраняется).
- Устанавливает флаги:
  - `ZF = 1` → элементы **равны**,
  - `ZF = 0` → элементы **не равны**.

**Использование префиксов:**

- `REPE`/`REPZ` — поиск первой **не совпадающей** пары элементов.
- `REPNE`/`REPNZ` — поиск первой **совпадающей** пары элементов.

**Важно:**

- После завершения цикла `ESI` и `EDI` указывают на **следующие** элементы после искомых.

---

#### **5. Сканирование цепочек (команды `SCASB/W/D`)**

**Назначение:** поиск значения в цепочке.
**Синтаксис:**

```asm
SCAS адрес_приёмника  ; Преобразуется в SCASB/W/D
```

**Алгоритм:**

- Сравнивает значение в регистре (`AL`/`AX`/`EAX`) с элементом по адресу `[EDI]`.
- Устанавливает флаги аналогично `CMPS`.

**Подготовка:**

- Искомое значение должно быть загружено в `AL` (байт), `AX` (слово) или `EAX` (двойное слово).

**Префиксы:**

- `REPE`/`REPZ` — поиск до первого **несовпадения**,
- `REPNE`/`REPNZ` — поиск до первого **совпадения**.

---

#### **6. Загрузка элемента в регистр (команды `LODSB/W/D`)**

**Синтаксис:**

```asm
LODS адрес_источника  ; Преобразуется в LODSB/W/D
```

**Действие:**

- Копирует элемент из `[ESI]` в регистр:
  - `LODSB` → `AL`,
  - `LODSW` → `AX`,
  - `LODSD` → `EAX`.
- Автоматически корректирует `ESI` в зависимости от `DF` и размера элемента.

---

#### **7. Сохранение регистра в цепочке (команды `STOSB/W/D`)**

**Синтаксис:**

```asm
STOS адрес_приёмника  ; Преобразуется в STOSB/W/D
```

**Действие:**

- Копирует значение из регистра в ячейку `[EDI]`:
  - `STOSB` → из `AL`,
  - `STOSW` → из `AX`,
  - `STOSD` → из `EAX`.
- Автоматически корректирует `EDI` в зависимости от `DF` и размера элемента.

**Пример (заполнение памяти значением 5):**

```asm
MOV AL, 5
LEA EDI, буфер
MOV ECX, 100
CLD
REP STOSB  ; заполнит 100 байт в буфере значением 5
```

---

**Ключевые особенности всех цепочечных команд:**

- Автоматическая коррекция `ESI`/`EDI` после каждой операции.
- Зависимость размера операндов от суффикса команды (`B`/`W`/`D`).
- Обязательная инициализация регистров `ESI`, `EDI`, `ECX` и флага `DF` перед выполнением.
