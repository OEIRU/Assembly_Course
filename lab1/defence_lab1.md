## 1. Работа с консолью Windows (API)

### `GetStdHandle`

* **Назначение**: получение дескриптора стандартного устройства.
* **Параметры**:
  
  * `-10` → `STD_INPUT_HANDLE` (ввод)
  * `-11` → `STD_OUTPUT_HANDLE` (вывод)
  * `-12` → `STD_ERROR_HANDLE` (ошибки)
* **Возврат**: дескриптор в `EAX`.
* Пример
  
  ```wasm
  push -11
  call GetStdHandle@4
  mov hStdOut, eax
  ```

### `WriteConsoleA`

* **Назначение**: вывод строки в консоль.
* **Параметры (в стек, справа налево)**:
  
  1. Дескриптор вывода (`hStdOut`)
  2. Указатель на строку
  3. Количество символов
  4. Адрес переменной для записи количества выведенных символов
  5. Резерв (всегда `0`)
* **Пример**:
  
  ```wasm
  push 0
  push offset bytesWritten
  push eax          ; длина строки
  push offset msg
  push hStdOut
  call WriteConsoleA@20
  ```

### `ReadConsoleA`

* **Назначение**: чтение строки из консоли (включая `\r\n`).
* **Параметры**:
  1. Дескриптор ввода (`hStdIn`)
  2. Адрес буфера
  3. Макс. длина буфера
  4. Адрес переменной для количества прочитанных символов
  5. Резерв (`0`)
* **Особенность**: нужно удалять последние 2 символа (`\r\n`) вручную.

### `CharToOemA`

* **Назначение**: преобразует ANSI-строку в OEM-кодировку (для корректного отображения в консоли Windows).
* **Параметры**:
  1. Указатель на исходную строку
  2. Указатель на буфер результата (может совпадать с исходной)

### `wsprintfA`

* **Назначение**: форматированный вывод (аналог `printf`).
* **Параметры**:
  
  1. Буфер результата
  2. Строка формата (`"Число %d", 0`)
  3. Список значений
* Пример:
  
  ```wasm
  push 123
  push offset fmt
  push offset buf
  call wsprintfA
  ```
  
  ## 2. Основные команды ассемблера
  
  ### `mov`
  
  * **Назначение**: копирование данных.
  * **Синтаксис**: `mov приёмник, источник`
  * **Пример**: `mov eax, 5`
  
  ### Стек: `push` / `pop`
  
  * **Стек растёт вниз** (в сторону младших адресов).
  * `push reg` → уменьшает `ESP` на 4 (в 32-битном режиме), кладёт значение.
  * `pop reg` → читает значение, увеличивает `ESP` на 4.
  * **Используется для передачи аргументов в функции** (STDCALL).
  
  ### Работа с флагами
  
  * `pushf` / `popf` — сохраняют/восстанавливают регистр флагов.
  * Полезны при написании процедур, не меняющих флаги.

## 3. Арифметические операции

### Сложение

* `add dest, src` — сложение без учёта переноса.
* `adc dest, src` — сложение **с учётом флага переноса CF** (для многобайтовых чисел).

### Вычитание

* `sub dest, src` — вычитание.
* `sbb dest, src` — вычитание **с заёмом** (аналог `adc` для вычитания).

### Умножение

* `mul src` — беззнаковое умножение.
* `imul src` — знаковое умножение.
* Результат: младшая часть — в `EAX`, старшая — в `EDX`.
* Флаги `CF`/`OF` указывают на переполнение.

### Деление

* `div src` — беззнаковое деление (`EDX:EAX / src`).
* `idiv src` — знаковое деление.
* Частное → `EAX`, остаток → `EDX`.

## 4. Директивы определения данных

| Директива | Размер | Пример                             |
| ------------------ | ------------ | ---------------------------------------- |
| `DB`               | 1 байт   | `msg DB "Hello", 0`                      |
| `DW`               | 2 байта | `word_val DW 1234h`                      |
| `DD`               | 4 байта | `dword_val DD 12345678h`                 |
| `DQ`               | 8 байт   | (редко в 32-битном коде) |

## 5. Способы адресации

### Регистровая

* Операнд в регистре: `mov eax, ebx`

### Непосредственная

* Константа в команде: `mov eax, 42`

### Прямая

* Обращение по имени переменной: `mov eax, [myVar]`

### Косвенная регистровая

+ Через регистр в квадратных скобках:
  
  ```wasm
  mov esi, offset buf
  mov al, [esi]   ; загрузка первого байта
  ```

### Адресация по базе + индекс

+ Для массивов и строк:
  ```wasm
  mov al, [esi + ecx]   ; esi — база, ecx — индекс
  ```

* Удобна в циклах (`REP MOVSB`, обработка строк и т.п.).
